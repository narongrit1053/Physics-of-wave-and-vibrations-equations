Lecture 0: Mathematical Foundations & Prerequisites

Topic 0.1: Quadratic Equations & Root Finding

  • Standard Quadratic Equation: $$a x^2 + b x + c = 0$$
  • Quadratic Formula for Roots: $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
  • Auxiliary Polynomial for ODE ($p^2 + \beta p + \omega_0^2 = 0$): $$p = -\frac{\beta}{2} \pm \sqrt{\frac{\beta^2}{4} - \omega_0^2}$$
  • Discriminant Classification ($\Delta = \frac{\beta^2}{4} - \omega_0^2$): $$\Delta > 0 \implies \text{Two distinct real roots (Overdamped)}$$ $$\Delta = 0 \implies \text{Repeated real root } p = -\frac{\beta}{2} \text{ (Critically Damped)}$$ $$\Delta < 0 \implies \text{Complex conjugate pair } p = -\frac{\beta}{2} \pm i\omega \text{ (Underdamped)}$$

Topic 0.2: Trigonometric Foundations & Euler's Formula

  • Euler's Formula: $$e^{i\theta} = \cos\theta + i\sin\theta$$
  • Polar Form of Complex Number: $$z = a + ib = R e^{i\theta} \quad \left(R = \sqrt{a^2 + b^2}, \quad \theta = \tan^{-1}\left(\frac{b}{a}\right)\right)$$
  • Linear Combination of Sine & Cosine to Single Harmonic Phase Form: $$A \cos\omega t + B \sin\omega t = R \cos(\omega t - \phi)$$ $$\text{where } R = \sqrt{A^2 + B^2}, \quad \phi = \tan^{-1}\left(\frac{B}{A}\right)$$
  • Cosine Phase Expansion: $$\cos(\omega t + \phi) = \cos(\omega t)\cos\phi - \sin(\omega t)\sin\phi$$

Topic 0.3: The Ansatz Technique (Trial Solutions for ODEs)

  • Exponential Trial Solution (Ansatz): $$x(t) = C e^{p t}$$
  • Derivatives of Exponential Ansatz: $$\frac{dx}{dt} = p C e^{p t}, \quad \frac{d^2x}{dt^2} = p^2 C e^{p t}$$
  • Substitution into Linear ODE ($\frac{d^2x}{dt^2} + \omega_0^2 x = 0$): $$p^2 C e^{pt} + \omega_0^2 C e^{pt} = 0 \implies p^2 + \omega_0^2 = 0 \implies p = \pm i\omega_0$$
  • Polynomial-Exponential Ansatz for Repeated Roots ($\Delta = 0$): $$x(t) = (C_1 + C_2 t) e^{p t}$$

Topic 0.4: Useful Trigonometric Identities

  • Pythagorean Identity: $$\sin^2 A + \cos^2 A = 1$$
  • Negative Angle Identities: $$\sin(-A) = -\sin A, \quad \cos(-A) = \cos A, \quad \tan(-A) = -\tan A$$
  • Angle Sum & Difference Identities: $$\sin(A \pm B) = \sin A \cos B \pm \cos A \sin B$$ $$\cos(A \pm B) = \cos A \cos B \mp \sin A \sin B$$ $$\tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A \tan B}$$
  • Cofunction & Double Angle Identities: $$\sin\left(\frac{\pi}{2} - A\right) = \cos A$$ $$\sin(2A) = 2\sin A\cos A$$ $$\cos(2A) = \cos^2 A - \sin^2 A = 1 - 2\sin^2 A$$ $$\tan(2A) = \frac{2\tan A}{1 - \tan^2 A}$$
  • Sum-to-Product Identities: $$\sin A + \sin B = 2\sin\left(\frac{A+B}{2}\right)\cos\left(\frac{A-B}{2}\right)$$ $$\sin A - \sin B = 2\cos\left(\frac{A+B}{2}\right)\sin\left(\frac{A-B}{2}\right)$$ $$\cos A + \cos B = 2\cos\left(\frac{A+B}{2}\right)\cos\left(\frac{A-B}{2}\right)$$ $$\cos A - \cos B = -2\sin\left(\frac{A+B}{2}\right)\sin\left(\frac{A-B}{2}\right)$$
  • Product-to-Sum Identities: $$\sin A \sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$$ $$\cos A \cos B = \frac{1}{2}[\cos(A-B) + \cos(A+B)]$$ $$\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$$ $$\cos A \sin B = \frac{1}{2}[\sin(A+B) - \sin(A-B)]$$
