Lecture 0: Mathematical Foundations & Prerequisitesบทที่ 0: พื้นฐานทางคณิตศาสตร์ที่จำเป็น

Topic 0.1: Quadratic Equations & Root Findingหัวข้อ 0.1: สมการกำลังสองและการหาคำตอบ

  • Standard Quadratic Equation:สมการกำลังสองมาตรฐาน: $$a x^2 + b x + c = 0$$
  • Quadratic Formula for Roots:สูตรการหาคำตอบสมการกำลังสอง: $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
  • Auxiliary Polynomial for ODE ($p^2 + \beta p + \omega_0^2 = 0$): $$p = -\frac{\beta}{2} \pm \sqrt{\frac{\beta^2}{4} - \omega_0^2}$$
  • Discriminant Classification ($\Delta = \frac{\beta^2}{4} - \omega_0^2$): $$\Delta > 0 \implies \text{Two distinct real roots (Overdamped)}$$ $$\Delta = 0 \implies \text{Repeated real root } p = -\frac{\beta}{2} \text{ (Critically Damped)}$$ $$\Delta < 0 \implies \text{Complex conjugate pair } p = -\frac{\beta}{2} \pm i\omega \text{ (Underdamped)}$$

Topic 0.2: Trigonometric Foundations & Euler's Formulaหัวข้อ 0.2: พื้นฐานตรีโกณมิติและสูตรของออยเลอร์

  • Euler's Formula:สูตรของออยเลอร์: $$e^{i\theta} = \cos\theta + i\sin\theta$$
  • Polar Form of Complex Number:รูปแบบโพลาร์ของจำนวนเชิงซ้อน:Key Formulaสูตรสำคัญ $$z = a + ib = R e^{i\theta} \quad \left(R = \sqrt{a^2 + b^2}, \quad \theta = \tan^{-1}\left(\frac{b}{a}\right)\right)$$
  • Linear Combination of Sine & Cosine to Single Harmonic Phase Form: $$A \cos\omega t + B \sin\omega t = R \cos(\omega t - \phi)$$ $$\text{where } R = \sqrt{A^2 + B^2}, \quad \phi = \tan^{-1}\left(\frac{B}{A}\right)$$
  • Cosine Phase Expansion:การกระจายเฟสของคอส (Cosine): $$\cos(\omega t + \phi) = \cos(\omega t)\cos\phi - \sin(\omega t)\sin\phi$$

Topic 0.3: The Ansatz Technique (Trial Solutions for ODEs)หัวข้อ 0.3: เทคนิคการตั้งคำตอบสมมติ (Ansatz)

  • Exponential Trial Solution (Ansatz): $$x(t) = C e^{p t}$$
  • Derivatives of Exponential Ansatz: $$\frac{dx}{dt} = p C e^{p t}, \quad \frac{d^2x}{dt^2} = p^2 C e^{p t}$$
  • Substitution into Linear ODE ($\frac{d^2x}{dt^2} + \omega_0^2 x = 0$): $$p^2 C e^{pt} + \omega_0^2 C e^{pt} = 0 \implies p^2 + \omega_0^2 = 0 \implies p = \pm i\omega_0$$
  • Polynomial-Exponential Ansatz for Repeated Roots ($\Delta = 0$): $$x(t) = (C_1 + C_2 t) e^{p t}$$

Topic 0.4: Useful Trigonometric Identitiesหัวข้อ 0.4: เอกลักษณ์ตรีโกณมิติที่สำคัญ

  • Pythagorean Identity: $$\sin^2 A + \cos^2 A = 1$$
  • Negative Angle Identities: $$\sin(-A) = -\sin A, \quad \cos(-A) = \cos A, \quad \tan(-A) = -\tan A$$
  • Angle Sum & Difference Identities: $$\sin(A \pm B) = \sin A \cos B \pm \cos A \sin B$$ $$\cos(A \pm B) = \cos A \cos B \mp \sin A \sin B$$ $$\tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A \tan B}$$
  • Cofunction & Double Angle Identities:Key Formulaสูตรสำคัญ $$\sin\left(\frac{\pi}{2} - A\right) = \cos A$$ $$\sin(2A) = 2\sin A\cos A$$ $$\cos(2A) = \cos^2 A - \sin^2 A = 1 - 2\sin^2 A$$ $$\tan(2A) = \frac{2\tan A}{1 - \tan^2 A}$$
  • Sum-to-Product Identities: $$\sin A + \sin B = 2\sin\left(\frac{A+B}{2}\right)\cos\left(\frac{A-B}{2}\right)$$ $$\sin A - \sin B = 2\cos\left(\frac{A+B}{2}\right)\sin\left(\frac{A-B}{2}\right)$$ $$\cos A + \cos B = 2\cos\left(\frac{A+B}{2}\right)\cos\left(\frac{A-B}{2}\right)$$ $$\cos A - \cos B = -2\sin\left(\frac{A+B}{2}\right)\sin\left(\frac{A-B}{2}\right)$$
  • Product-to-Sum Identities:Key Formulaสูตรสำคัญ $$\sin A \sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$$ $$\cos A \cos B = \frac{1}{2}[\cos(A-B) + \cos(A+B)]$$ $$\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$$ $$\cos A \sin B = \frac{1}{2}[\sin(A+B) - \sin(A-B)]$$

Topic 0.5: Coordinate Systems ($x$-$y$ Axis, $\text{Re}$-$\text{Im}$ Complex Axis & $\cos$-$\sin$ Projections)หัวข้อ 0.5: ระบบพิกัดและแกน ($x$-$y$, $\text{Re}$-$\text{Im}$, $\cos$-$\sin$)

  • 2D Cartesian Coordinate System ($x$-$y$ Axis): $$\text{Position Vector: } \vec{r} = x\hat{i} + y\hat{j}, \quad \text{Magnitude: } r = \sqrt{x^2 + y^2}, \quad \text{Angle: } \theta = \tan^{-1}\left(\frac{y}{x}\right)$$
  • Complex Plane / Argand Diagram ($\text{Re}$-$\text{Im}$ Axis): $$\text{Complex Number: } z = x + i y = R e^{i\theta}$$ $$\text{Real Axis (Horizontal): } x = \text{Re}[z] = R \cos\theta$$ $$\text{Imaginary Axis (Vertical): } y = \text{Im}[z] = R \sin\theta$$
  • Cosine Axis & Sine Axis Projections: $$\text{Horizontal Axis } (\text{Cosine Axis}) \implies \text{Adjacent component } x = R\cos\theta$$ $$\text{Vertical Axis } (\text{Sine Axis}) \implies \text{Opposite component } y = R\sin\theta$$
  • Quadrant Classifications & Algebraic Signs: $$\text{Quadrant I } (0 < \theta < \pi/2): x > 0, \, y > 0 \quad (\cos\theta > 0, \, \sin\theta > 0)$$ $$\text{Quadrant II } (\pi/2 < \theta < \pi): x < 0, \, y > 0 \quad (\cos\theta < 0, \, \sin\theta > 0)$$ $$\text{Quadrant III } (\pi < \theta < 3\pi/2): x < 0, \, y < 0 \quad (\cos\theta < 0, \, \sin\theta < 0)$$ $$\text{Quadrant IV } (3\pi/2 < \theta < 2\pi): x > 0, \, y < 0 \quad (\cos\theta > 0, \, \sin\theta < 0)$$

Topic 0.6: The Unit Circle & Trigonometric Mappingหัวข้อ 0.6: วงกลมหนึ่งหน่วยและการส่งแปลงทางตรีโกณมิติ

  • Unit Circle Equation ($R = 1$): $$x^2 + y^2 = 1 \implies \cos^2\theta + \sin^2\theta = 1$$
  • Phasor Point Mapping on Unit Circle: $$\text{Point } P(\theta) = (\cos\theta, \, \sin\theta) = e^{i\theta} = \cos\theta + i\sin\theta$$
  • Exact Values at Key Angles $\theta$: $$\begin{array}{|c|c|c|c|c|c|c|c|c|} \hline \text{Angle } \theta \text{ (deg)} & 0^\circ & 30^\circ & 45^\circ & 60^\circ & 90^\circ & 180^\circ & 270^\circ & 360^\circ \\ \hline \text{Angle } \theta \text{ (rad)} & 0 & \frac{\pi}{6} & \frac{\pi}{4} & \frac{\pi}{3} & \frac{\pi}{2} & \pi & \frac{3\pi}{2} & 2\pi \\ \hline \cos\theta \, (\text{Re}) & 1 & \frac{\sqrt{3}}{2} & \frac{\sqrt{2}}{2} & \frac{1}{2} & 0 & -1 & 0 & 1 \\ \hline \sin\theta \, (\text{Im}) & 0 & \frac{1}{2} & \frac{\sqrt{2}}{2} & \frac{\sqrt{3}}{2} & 1 & 0 & -1 & 0 \\ \hline \end{array}$$
