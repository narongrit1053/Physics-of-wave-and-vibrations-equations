Lecture 5: LC Circuit Oscillationsบทที่ 5: การสั่นในวงจรไฟฟ้า LC

Interactive Physics Visualizer: LC Circuit & Phase Relationships ($q$, $i$, $V_L$)

Topic 5.1: Differential Equations & Natural Frequencyหัวข้อ 5.1: สมการเชิงอนุพันธ์และความถี่ธรรมชาติ

  • KVL Loop Equation: $$-\frac{q}{C} - L\frac{di}{dt} = 0 \implies L\frac{d^2q}{dt^2} + \frac{1}{C}q = 0 \quad \left(\text{since } i = \frac{dq}{dt}\right)$$
  • Standard Form: $$\frac{d^2q}{dt^2} + \frac{1}{LC} q = 0$$
  • Natural Angular Frequency:Key Formulaสูตรสำคัญ $$\omega_0 = \frac{1}{\sqrt{LC}}$$
  • Charge Solution: $$q(t) = q_0 \cos(\omega_0 t + \phi)$$

Topic 5.2: LC Circuit Energy Conservationหัวข้อ 5.2: การอนุรักษ์พลังงานในวงจร LC

  • Total Electrical Energy ($E$):Key Formulaสูตรสำคัญ $$E = U_E + U_B = \frac{1}{2C} q^2 + \frac{1}{2} L i^2 = \text{constant}$$
  • Energy Conservation Proof:Key Formulaสูตรสำคัญ $$\frac{dE}{dt} = \frac{d}{dt}\left(\frac{1}{2C} q^2 + \frac{1}{2} L i^2\right) = 0 \implies \frac{q}{C}\frac{dq}{dt} + L i \frac{di}{dt} = 0 \implies \ddot{q} + \frac{1}{LC} q = 0$$

Topic 5.3: Phase Diagrams — Capacitor & Inductorหัวข้อ 5.3: ไดอะแกรมเฟส — ตัวเก็บประจุและตัวเหนี่ยวนำ

Capacitor: Voltage lags Current by $90°$ ($-\frac{\pi}{2}$)

For a capacitor driven by $i(t) = i_0 e^{i\omega t}$, the voltage is: $$V_C = \frac{1}{i\omega C}\, i_0 e^{i\omega t} = \frac{i_0}{\omega C}\, e^{i(\omega t - \pi/2)}$$ The impedance is $Z_C = \frac{1}{i\omega C}$, so $V_C$ lags $i$ by $90°$.

Inductor: Voltage leads Current by $90°$ ($+\frac{\pi}{2}$)

For an inductor driven by $i(t) = i_0 e^{i\omega t}$, the voltage is: $$V_L = i\omega L\, i_0 e^{i\omega t} = \omega L\, i_0\, e^{i(\omega t + \pi/2)}$$ The impedance is $Z_L = i\omega L$, so $V_L$ leads $i$ by $90°$.

  • Capacitor Impedance:Key Formulaสูตรสำคัญ $$Z_C = \frac{1}{i\omega C} = \frac{1}{\omega C}\, e^{-i\pi/2} \quad \Rightarrow \quad V_C \text{ lags } i \text{ by } 90°$$
  • Inductor Impedance:Key Formulaสูตรสำคัญ $$Z_L = i\omega L = \omega L\, e^{i\pi/2} \quad \Rightarrow \quad V_L \text{ leads } i \text{ by } 90°$$
  • Resistor (Reference):Key Formulaสูตรสำคัญ $$Z_R = R \quad \Rightarrow \quad V_R \text{ is in phase with } i$$
