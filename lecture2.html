Lecture 2: Superposition of Periodic Motions

Interactive Physics Visualizer: Superposition Dynamics across Topics

Topic 2.1: Superposition of Two SHMs (Same Frequency, One Dimension)

  • Sum of Oscillations: $$x = x_1 + x_2 = A_1 \cos(\omega t + \phi_1) + A_2 \cos(\omega t + \phi_2) = A \cos(\omega t + \phi)$$
  • Resultant Amplitude (Law of Cosines): $$A^2 = A_1^2 + A_2^2 + 2A_1 A_2 \cos(\varphi_2 - \varphi_1)$$
  • Inner Triangle Geometry Calculation: $$A^2 = A_1^2 + A_2^2 - 2A_1 A_2 \cos(180^\circ - (\varphi_2 - \varphi_1))$$
  • Resultant Phase Angle $\beta$ (Law of Sines): $$A \sin\beta = A_2 \sin(\varphi_2 - \varphi_1) \quad (\text{where } \phi = \phi_1 + \beta)$$
  • Complex Superposition Formulation: $$z = z_1 + z_2 = A_1 e^{i(\omega t + \varphi_1)} + A_2 e^{i(\omega t + \varphi_2)} = e^{i(\omega t + \varphi_1)}\left[A_1 + A_2 e^{i(\varphi_2 - \varphi_1)}\right]$$

Topic 2.2: Equal Amplitudes Special Case

  • Phase Angle Split (when $A_1 = A_2$): $$\beta = \frac{\delta}{2} \quad (\text{where } \delta = \varphi_2 - \varphi_1)$$
  • Resultant Amplitude: $$A = 2A_1 \cos\beta = 2A_1 \cos\left(\frac{\delta}{2}\right)$$

Topic 2.3: Superposition of Different Frequencies (Beats)

  • Superposed Beat Position: $$x = x_1 + x_2 = A \cos\omega_1 t + A \cos\omega_2 t = 2A \cos\left(\frac{\omega_1 + \omega_2}{2} t\right) \cos\left(\frac{\omega_1 - \omega_2}{2} t\right)$$
  • Beat Period: $$T_{\text{beat}} = \frac{2\pi}{|\omega_1 - \omega_2|}$$

Topic 2.4: Superposition of Perpendicular Vibrations (Two Dimensions)

  • Component Equations: $$x = A_1 \cos(\omega t + \phi_1), \quad y = A_2 \cos(\omega t + \phi_2)$$
  • Common Reference Form ($\phi_1 = 0, \phi_2 = \phi$): $$x = A_1 \cos(\omega t), \quad y = A_2 \cos(\omega t + \phi)$$
  • General Elliptical Trajectory ($A_1 = A_2 = A$): $$x^2 - 2xy \cos\phi + y^2 = A^2 \sin^2\phi$$
  • Special Trajectories (Lissajous Curves):
    • $\phi = 0$ (In-phase Rectilinear): $y = \frac{A_2}{A_1} x$
    • $\phi = \pi/2$ (Clockwise Ellipse): $\frac{x^2}{A_1^2} + \frac{y^2}{A_2^2} = 1$
    • $\phi = \pi$ (Out-of-phase Rectilinear): $y = -\frac{A_2}{A_1} x$
    • $\phi = 3\pi/2$ (Counter-Clockwise Ellipse): $\frac{x^2}{A_1^2} + \frac{y^2}{A_2^2} = 1$
    • $\phi = \pi/4$ (Rotated Clockwise Ellipse): $y = \frac{\sqrt{2}}{2} A_2 \cos\omega t - \frac{\sqrt{2}}{2} A_2 \sin\omega t$

Topic 2.5: Parallel vs. Perpendicular Superposition Summary

  • Parallel Superposition: $$y = y_1 + y_2 = \left(2A \cos\frac{\varphi}{2}\right) \cos\left(\omega t + \frac{\varphi}{2}\right)$$
  • Perpendicular Superposition: $$x^2 - 2xy \cos\varphi + y^2 = A^2 \sin^2\varphi$$
