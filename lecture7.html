Lecture 7: Forced Oscillations and Resonance

Topic 7.1: Forced Mechanical Oscillations

  • Equation of Motion: $$m \ddot{x} + b \dot{x} + k x = F_0 \cos\omega t \implies \ddot{x} + \beta \dot{x} + \omega_0^2 x = \frac{F_0}{m} \cos\omega t$$
  • General Solution (Transient + Steady-State): $$x(t) = x_{\text{trans}}(t) + x_{\text{steady}}(t) = B e^{-\frac{\beta}{2} t} \cos(\omega_d t + \phi) + A(\omega) \cos(\omega t - \delta)$$
  • Steady-State Amplitude $A(\omega)$: $$A(\omega) = \frac{F_0 / m}{\sqrt{(\omega_0^2 - \omega^2)^2 + \omega^2 \beta^2}}$$
  • Phase Difference $\delta$: $$\tan\delta = \frac{\omega \beta}{\omega_0^2 - \omega^2}$$

Topic 7.2: Series RLC Circuit

  • KVL Loop with AC Source: $$L \frac{d^2q}{dt^2} + R \frac{dq}{dt} + \frac{1}{C} q = V_0 \cos\omega t$$
  • Steady-State Charge Amplitude: $$q_0(\omega) = \frac{V_0 / L}{\sqrt{(\omega_0^2 - \omega^2)^2 + \omega^2 \beta^2}}$$
  • Phase Shift: $$\tan\delta = \frac{\omega \beta}{\omega_0^2 - \omega^2}$$
  • Circuit Current: $$i(t) = \frac{dq}{dt} = -q_0 \omega \sin(\omega t - \delta)$$

Topic 7.3: Complex Impedance Analysis

  • Device Impedances: $$Z_R = R, \quad Z_L = j\omega L, \quad Z_C = -\frac{j}{\omega C}$$
  • Total Impedance ($Z$): $$Z = R + i\left(\omega L - \frac{1}{\omega C}\right)$$
  • Impedance Magnitude: $$|Z| = \sqrt{R^2 + \left(\omega L - \frac{1}{\omega C}\right)^2}$$
  • Phase Angle: $$\tan\delta = \frac{\omega L - \frac{1}{\omega C}}{R}$$
  • Ohm's Law Real Component Current: $$i(t) = \frac{V_0}{\sqrt{R^2 + \left(\omega L - \frac{1}{\omega C}\right)^2}} \cos(\omega t - \delta)$$

Topic 7.4: Electrical Resonance

  • Resonance Condition: $$\omega L = \frac{1}{\omega C} \implies \omega_0 = \frac{1}{\sqrt{LC}}$$
  • Characteristics at Resonance:
    • Impedance Phase: $\delta = 0$
    • Impedance Magnitude: $|Z| = R$
    • Max Current Amplitude: $I_{\text{max}} = \frac{V_0}{R}$
    • Reduced Current Equation: $i(t) = \frac{V_0}{R} \cos\omega t$
