Lecture 8: Coupled Oscillations

Interactive Physics Visualizer: Coupled Pendulum System & Normal Modes

Topic 8.1: Single Pendulum (Basic SHM Reference)

  • Nonlinear Differential Equation of Motion: $$\ddot{\theta} + \omega_0^2 \sin \theta = 0$$
  • Linearized Equation ($\sin\theta \approx \theta$): $$\ddot{\theta} + \omega_0^2 \theta = 0 \implies \ddot{x} + \omega_0^2 x = 0$$
  • Natural Angular Frequency: $$\omega_0 = \sqrt{\frac{g}{L}} \implies \omega_0^2 = \frac{g}{L}$$
  • Analytical Displacement Solution: $$x(t) = A \cos(\omega_0 t + \phi)$$

Topic 8.2: Coupled Pendulums (Horizontal Spring Link)

  • Coupling Spring Restoring Forces ($k_c$): $$F_A = -k_c(x_A - x_B)$$ $$F_B = k_c(x_A - x_B) = -k_c(x_B - x_A)$$
  • Newton's 2nd Law Equations: $$m\ddot{x}_A = -m\omega_0^2 x_A - k_c(x_A - x_B)$$ $$m\ddot{x}_B = -m\omega_0^2 x_B + k_c(x_A - x_B)$$
  • Normalized Coupled Differential Equations ($\omega_c^2 = \frac{k_c}{m}$): $$\ddot{x}_A + \omega_0^2 x_A + \omega_c^2(x_A - x_B) = 0$$ $$\ddot{x}_B + \omega_0^2 x_B - \omega_c^2(x_A - x_B) = 0$$

Topic 8.3: Coordinate Decoupling Method (Sum & Difference)

  • Sum Equation: $$(\ddot{x}_A + \ddot{x}_B) + \omega_0^2(x_A + x_B) = 0$$
  • Difference Equation: $$(\ddot{x}_A - \ddot{x}_B) + (\omega_0^2 + 2\omega_c^2)(x_A - x_B) = 0$$
  • Normal Coordinates Definition ($q_1, q_2$): $$q_1 = x_A + x_B, \quad q_2 = x_A - x_B$$
  • Independent Differential Equations for Normal Coordinates: $$\ddot{q}_1 + \omega_0^2 q_1 = 0$$ $$\ddot{q}_2 + \omega'^2 q_2 = 0 \quad \left(\text{where } \omega' = \sqrt{\omega_0^2 + 2\omega_c^2}\right)$$

Topic 8.4: Normal Coordinates & Mode Solutions

  • Decoupled Normal Coordinate Solutions: $$q_1(t) = A \cos(\omega_0 t + \phi)$$ $$q_2(t) = B \cos(\omega' t + \alpha)$$
  • Physical Displacements Mapping: $$x_A(t) = \frac{1}{2}(q_1 + q_2), \quad x_B(t) = \frac{1}{2}(q_1 - q_2)$$
  • Complete Superposition Solutions: $$x_A(t) = \frac{A}{2} \cos(\omega_0 t + \phi) + \frac{B}{2} \cos(\omega' t + \alpha)$$ $$x_B(t) = \frac{A}{2} \cos(\omega_0 t + \phi) - \frac{B}{2} \cos(\omega' t + \alpha)$$

Topic 8.5: Matrix Method for Coupled Systems

  • Harmonic Trial Solutions: $$x_A(t) = x_A \cos(\omega t + \phi) \implies \ddot{x}_A(t) = -\omega^2 x_A$$ $$x_B(t) = x_B \cos(\omega t + \alpha) \implies \ddot{x}_B(t) = -\omega^2 x_B$$
  • Substituted Linear System: $$-\omega^2 x_A + (\omega_0^2 + \omega_c^2)x_A - \omega_c^2 x_B = 0$$ $$-\omega^2 x_B + (\omega_0^2 + \omega_c^2)x_B - \omega_c^2 x_A = 0$$
  • Matrix System Representation: $$\begin{bmatrix} \omega_0^2 + \omega_c^2 - \omega^2 & -\omega_c^2 \\ -\omega_c^2 & \omega_0^2 + \omega_c^2 - \omega^2 \end{bmatrix} \begin{bmatrix} x_A \\ x_B \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix}$$
  • Eigenvalue Determinant Condition: $$\det \begin{bmatrix} \omega_0^2 + \omega_c^2 - \omega^2 & -\omega_c^2 \\ -\omega_c^2 & \omega_0^2 + \omega_c^2 - \omega^2 \end{bmatrix} = 0$$
  • Characteristic Polynomial Equation ($\lambda = \omega^2$): $$(\omega_0^2 + \omega_c^2 - \omega^2)^2 - \omega_c^4 = 0 \implies \lambda^2 - 2\lambda(\omega_0^2 + \omega_c^2) + (\omega_0^2 + \omega_c^2)^2 - \omega_c^4 = 0$$
  • Normal Mode Frequencies (Eigenvalues): $$\omega_1 = \omega_0 = \sqrt{\frac{g}{L}} \quad \text{(Symmetric / Lower Frequency)}$$ $$\omega_2 = \omega' = \sqrt{\frac{g}{L} + \frac{2k_c}{m}} \quad \text{(Antisymmetric / Higher Frequency)}$$

Topic 8.6: Eigenvectors and Physical Behaviors of Modes

  • Symmetric Mode (Mode 1, In-Phase, $\omega^2 = \omega_0^2$): $$x_A = x_B \implies \mathbf{q}_1 = \begin{pmatrix} x_A \\ x_A \end{pmatrix} \propto \begin{pmatrix} 1 \\ 1 \end{pmatrix}$$
  • Antisymmetric Mode (Mode 2, Out-of-Phase, $\omega^2 = \omega_0^2 + 2\omega_c^2$): $$x_A = -x_B \implies \mathbf{q}_2 = \begin{pmatrix} x_A \\ -x_A \end{pmatrix} \propto \begin{pmatrix} 1 \\ -1 \end{pmatrix}$$

Topic 8.7: Single Pendulum Initial Excitation (Beats & Energy Modulation)

  • Initial Boundary Conditions ($x_A(0) = A_0, x_B(0) = 0, \dot{x}_A(0) = \dot{x}_B(0) = 0$): $$\phi = \alpha = 0 \implies A = B = A_0$$
  • Displacement Equations (Beats Modulation): $$x_A(t) = A_0 \cos\left(\frac{\omega' - \omega_0}{2} t\right)\cos\left(\frac{\omega' + \omega_0}{2} t\right)$$ $$x_B(t) = A_0 \sin\left(\frac{\omega' - \omega_0}{2} t\right)\sin\left(\frac{\omega' + \omega_0}{2} t\right)$$
  • Velocities of the Modulated Pendulums: $$\dot{x}_A(t) = -\frac{1}{2} A_0 \omega_0 \sin(\omega_0 t) - \frac{1}{2} A_0 \omega' \sin(\omega' t)$$ $$\dot{x}_B(t) = -\frac{1}{2} A_0 \omega_0 \sin(\omega_0 t) + \frac{1}{2} A_0 \omega' \sin(\omega' t)$$

Topic 8.8: Exercise 1: Horizontal Coupled Mass-Spring System

  • Coupled Differential Equations ($\omega_0^2 = \frac{k}{m}, \omega_c^2 = \frac{k_c}{m}$): $$\ddot{x}_A + \omega_0^2 x_A + \omega_c^2(x_A - x_B) = 0$$ $$\ddot{x}_B + \omega_0^2 x_B - \omega_c^2(x_A - x_B) = 0$$
  • Normal Mode Frequencies: $$\omega_s = \sqrt{\frac{k}{m}}, \quad \omega_f = \sqrt{\frac{k}{m} + \frac{2k_c}{m}}$$
  • Symmetric & Antisymmetric Superposition Solution: $$x_A(t) = A\cos(\omega_s t + \phi) + B\cos(\omega_f t + \alpha)$$ $$x_B(t) = A\cos(\omega_s t + \phi) - B\cos(\omega_f t + \alpha)$$

Topic 8.9: Exercise 2: Vertical Coupled Mass-Spring System

  • Differential Equations of Motion ($\omega_0^2 = \frac{k}{m}$): $$\frac{d^2 x_1}{dt^2} + 2\omega_0^2 x_1 - \omega_0^2 x_2 = 0$$ $$\frac{d^2 x_2}{dt^2} - \omega_0^2 x_1 + \omega_0^2 x_2 = 0$$
  • System Matrix Representation ($\lambda = \omega^2$): $$\begin{bmatrix} 2\omega_0^2 - \lambda & -\omega_0^2 \\ -\omega_0^2 & \omega_0^2 - \lambda \end{bmatrix} \begin{bmatrix} u_1 \\ u_2 \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix}$$
  • Characteristic Equation: $$\lambda^2 - 3\omega_0^2 \lambda + \omega_0^4 = 0$$
  • Normal Mode Frequencies (Eigenvalues): $$\omega^2 = (3 \pm \sqrt{5})\frac{k}{2m}$$
  • Normal Frequency Ratio: $$\frac{\omega_1}{\omega_2} = \frac{\sqrt{5} + 1}{\sqrt{5} - 1}$$
  • Relative Amplitude Ratio Formula: $$\frac{u_2}{u_1} = 2 - \frac{\omega^2}{\omega_0^2}$$
  • Mode 1 (High Frequency, Out-of-Phase, $\omega^2 = \frac{3+\sqrt{5}}{2}\omega_0^2$): $$\frac{u_2}{u_1} = \frac{1-\sqrt{5}}{2} \approx -0.618$$
  • Mode 2 (Low Frequency, In-Phase, $\omega^2 = \frac{3-\sqrt{5}}{2}\omega_0^2$): $$\frac{u_2}{u_1} = \frac{1+\sqrt{5}}{2} \approx +1.618$$
